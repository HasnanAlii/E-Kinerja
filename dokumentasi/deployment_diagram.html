Arsitektur Infrastruktur & Deployment Sistem Monitoring Kehadiran Karyawan PT Pou Yuen Indonesia

dep Deployment Diagram — Sistem Monitoring Kehadiran Karyawan PT Pou Yuen (YOLOv8 & CNN)

Keterangan Lengkap Setiap Node, Komponen, dan Artefak pada Diagram:

«device» Perangkat Atasan / Supervisor

Perangkat komputer/workstation yang digunakan oleh Atasan/Supervisor di PT Pou Yuen untuk mengendalikan pengawasan kamera, mengelola data karyawan, memverifikasi perizinan, dan mengunduh laporan kehadiran.

  • Web Browser (Dashboard & Canvas)
    Antarmuka web sisi klien berbasis HTML5 Canvas & Alpine.js untuk menampilkan video *real-time* 60 FPS, menggambar kotak zona kerja karyawan, memantau durasi 8 jam, dan mengakses dashboard analitik.
  • Kamera Pengawas CCTV / Webcam
    Perangkat sensor visual (resolusi HD `1280x720`) yang menangkap citra area meja/posisi kerja karyawan secara langsung untuk dikirimkan ke server AI.
«device» Perangkat Karyawan (PC / Mobile)

Perangkat komputer atau ponsel pintar milik karyawan PT Pou Yuen untuk mengakses layanan mandiri kehadiran.

  • Web Browser Karyawan
    Digunakan karyawan untuk mengecek riwayat kehadiran otomatis (filter harian & bulanan), melihat progres pemenuhan jam kerja 8 jam, mengajukan izin/sakit/cuti, mengelola data diri, serta mencetak laporan PDF pribadi (*Data Karyawan T1*).
«execution environment» Web Application Server (Laravel 12)

Server aplikasi utama berbasis PHP 8.3 & Framework Laravel 12 yang menangani seluruh proses bisnis, hak akses (*role*), dan pelaporan.

  • Monitoring & Kehadiran Controller
    Komponen pengelola halaman Monitoring Kamera (`AtasanMonitoringController`), rekap kehadiran harian/bulanan (`AtasanKehadiranController` & `KehadiranController`), serta pemblokiran absen manual.
  • Manajemen Karyawan & Izin/Cuti
    Komponen pengelola CRUD 7 atribut karyawan PT Pou Yuen (`PegawaiController`), pembaruan profil (`ProfilController`), serta pengajuan & persetujuan izin, sakit, dan cuti (`IzinSakitController`).
  • Generator Laporan PDF & Excel
    Artefak pencetak laporan menggunakan pustaka *DomPDF* (format *Data Karyawan T1* untuk perorangan dan format *Kop Resmi PT Pou Yuen* untuk seluruh karyawan) serta ekspor *CSV/Excel*.
  • Storage Disk
    Media penyimpanan berkas fisik pada server (`storage/app/public`) untuk menyimpan foto profil karyawan dan dokumen lampiran surat bukti izin/sakit/cuti.
«execution environment» AI Computer Vision Server (Port 5000)

Server komputasi visi berbasis Python yang memproses frame kamera dan menjalankan kecerdasan buatan pendeteksi kehadiran otomatis.

  • Flask REST API & Persistent Worker
    Layanan API (`app.py`) yang menerima kiriman frame kamera, mengelola titik koordinat zona (`/api/zones`), serta menjalankan *background thread* agar pengawasan tetap berjalan meskipun browser di-*reload* atau *logout*.
  • YOLOv8 (Deteksi & Lokalisasi Manusia)
    Model *single-stage object detector* (`yolov8n.pt`) yang bertugas **mendeteksi keberadaan objek manusia (`class = 0`)**, menentukan titik koordinat kotak batas (*bounding box* `x1, y1, x2, y2`), dan menghitung *confidence score* ($\ge 0.50$) secara *real-time*.
  • Backbone CNN (Ekstraksi Fitur Visual)
    Jaringan saraf konvolusional (*CSPDarknet / C2f*) yang bertugas **mengekstraksi fitur visual spasial** (kontur kepala, bahu, dan proporsi postur tubuh manusia) dari gambar mentah sehingga sistem tidak salah mendeteksi kursi/meja kosong, monitor, atau bayangan sebagai manusia.
  • Zone Recognition & 8-Hour Engine
    Mesin logika (`ai/vision.py`) yang mencocokkan irisan posisi tubuh karyawan dengan zona kerja (*overlap* $\ge 20\%$), menerapkan konfirmasi beruntun (*streak* $\ge 2$ frame), mencatat *Check-In* (pertama terdeteksi) & *Check-Out* (terakhir terdeteksi), serta menghitung progres jam kerja terhadap standar **8 Jam**.
«database server» MySQL Database Server (Port 3306)

Server basis data relasional terpusat yang mengintegrasikan data antara aplikasi web Laravel dan server AI Python.

  • Database e_kinerja (PT Pou Yuen)
    Skema basis data utama yang memuat tabel `users`, `pegawai_details` (data 30+ karyawan PT Pou Yuen), `zona_kameras` (koordinat zona duduk), `kehadirans` (jam masuk/pulang otomatis), `cctv_monitoring_logs` (akumulasi durasi kerja), dan `izin_sakit`.

Keterangan Jalur Komunikasi & Protokol Jaringan:

  • «HTTP/JSON» REST API :5000
    Jalur komunikasi dari browser Atasan ke AI Computer Vision Server untuk mengirim frame video kamera, menyimpan/mengambil koordinat zona, dan mengambil status deteksi *real-time*.
  • «HTTP/HTTPS» Port 8000 (Atasan → Web Server)
    Jalur komunikasi dari browser Atasan ke Web Application Server (Laravel 12) untuk mengakses dashboard, mengelola data karyawan, memverifikasi izin/cuti, dan mengunduh laporan PDF/Excel.
  • «HTTP/HTTPS» (Karyawan → Web Server)
    Jalur komunikasi dari perangkat Karyawan ke Web Application Server (Laravel 12) untuk melihat rekap kehadiran pribadi, mengajukan izin/sakit/cuti, dan mencetak PDF *Data Karyawan (T1)*.
  • «TCP/IP» PyMySQL :3306
    Koneksi database dari AI Computer Vision Server (menggunakan *SQLAlchemy & PyMySQL*) ke MySQL Database Server untuk membaca zona kamera serta menulis otomatis jam *check-in*, *check-out*, dan durasi kerja.
  • «TCP/IP» PDO :3306
    Koneksi database dari Web Application Server Laravel (menggunakan *PHP Data Objects / Eloquent ORM* melewati jalur bawah) ke MySQL Database Server untuk membaca dan menyimpan seluruh data aplikasi.
