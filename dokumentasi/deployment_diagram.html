Keterangan Node & Komponen:

  • Client Workstation Perangkat fisik pengguna (PC/Smartphone) yang mengakses sistem melalui peramban (Web Browser).
  • Web Server Lingkungan yang mengeksekusi aplikasi web utama berbasis Laravel 12. Mengatur autentikasi, UI, manajemen folder, dan routing.
  • AI Microservice Server Lingkungan Python terpisah yang menjalankan layanan FastAPI. Bertugas melakukan ekstraksi fitur wajah (FaceNet), deteksi (MTCNN), dan clustering (DBSCAN).
  • Database Server Basis data relasional MySQL yang menyimpan metadata file, data pengguna, serta vektor face embedding.
  • Storage Host Sistem file lokal (Local Disk) tempat menyimpan aset gambar fisik. Laravel memiliki akses baca-tulis, sedangkan layanan Python hanya memerlukan akses baca (Read-only) untuk pemrosesan citra.
