1 Penambahan Foto — Deteksi MTCNN & Preprocessing

flowchart TD C1{1} --> B[/Membaca Foto/] B --> IP["Membentuk Image Pyramid\nberbagai skala resolusi"] IP --> PN["P-Net: Mendeteksi Kandidat\nArea Wajah Awal"] PN --> NMS1["Non-Maximum Suppression NMS\nMenghapus Bounding Box Bertumpuk"] NMS1 --> RN["R-Net: Menyaring Kandidat\nWajah yang Valid"] RN --> NMS2["Non-Maximum Suppression NMS\nMenyempurnakan Bounding Box"] NMS2 --> ON["O-Net: Memvalidasi Wajah\ndan Menentukan 5 Titik Landmark"] ON --> BB["Menghasilkan Bounding Box\ndan Titik Landmark Wajah"] BB --> Q1{Wajah\nTerdeteksi?} Q1 -->|Tidak| IG["Mengabaikan Foto\n( tidak ada wajah )"] IG --> B Q1 -->|Iya| CW["Crop Wajah\nsesuai Bounding Box"] CW --> RS["Resize menjadi\n160x160 pixel"] RS --> NM["Normalisasi Nilai Pixel\nx_norm = x / 255"] NM --> C3{3}

3→4 FaceNet — Ekstraksi Embedding 512 Dimensi

flowchart TD C3b{3} --> FD[Menerima Citra Wajah\nHasil Crop 160x160] FD --> FN["FaceNet InceptionResNetV1\nMelakukan Forward Pass"] FN --> EMB["Menghasilkan Vektor Embedding\n512 Dimensi per Wajah"] EMB --> NORM["Normalisasi L2 Embedding\ne_norm = e / ||e||"] NORM --> SAVE["Menyimpan Embedding ke DB\ntabel: face_embeddings"] SAVE --> C4{4}

4→5 DBSCAN Clustering — Pengelompokan Wajah Otomatis

flowchart TD C4b{4} --> PARAM["Menentukan Parameter\nε eps=0.25, MinPts=1, metric=cosine"] PARAM --> DIST["Menghitung Jarak Cosine\nAntar Semua Embedding\nd(x,y) = 1 - (x·y)/(|x||y|)"] DIST --> CORE["Identifikasi Core Points\n( tetangga dalam eps ≥ MinPts )"] CORE --> EXPAND["Ekspansi Cluster\nDensity-Reachable Points"] EXPAND --> NOISE["Tandai Noise Points\n( tidak punya cukup tetangga )"] NOISE --> VOTE["Majority Voting per Cluster\nCluster → Identitas Dominan"] VOTE --> SAVEC["Simpan Hasil Cluster ke DB\ntabel: face_clusters"] SAVEC --> C5{5}
